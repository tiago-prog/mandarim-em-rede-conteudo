# Arquivo histórico

Esta pasta contém materiais preservados para consulta, regressão ou rastreabilidade. Os arquivos aqui não fazem parte do fluxo PDF-first ativo.

| Pasta | Conteúdo |
|---|---|
| `legacy-content/` | JSONs, manifests e documentos da arquitetura anterior |
| `audio-scripts/` | Roteiros de áudio históricos; o produto atual não inclui áudio |
| `build-legacy/` | Pacote de build do fluxo legado |
| `prototypes/` | Protótipos e auditorias visuais anteriores |
| `snapshots/` | Snapshots e cópias compactadas do repositório |
