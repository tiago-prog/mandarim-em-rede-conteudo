# Política de Separação — Consulta × Produção × Resposta

## Regra oficial

> Consulta de um lado.  
> Produção de outro.  
> Resposta em outro lugar ainda.

Esta política existe para proteger a recuperação ativa.  
Se o aluno tem o apoio completo na mesma página do exercício, ele copia. Não recupera.

---

## O que NÃO pode ficar na mesma página

### Proibido na página de produção / recuperação / recombinação
- Banco de palavras completo
- Mapa de linguagem completo
- Frases de exemplo com tradução completa
- Gabarito / respostas
- Qualquer bloco que transforme a tarefa em cópia

### Permitido com restrição
- Molde de estrutura (ex.: `你是……吗？`)
- Instrução curta
- Situação/cenário
- Campo de escrita
- Checklist de autonomia

---

## Onde cada coisa deve ficar

| Conteúdo | Local correto |
|----------|----------------|
| Mapa de linguagem | Página própria de consulta |
| Banco de palavras | Página própria de consulta |
| Frases de exemplo | Página própria de referência |
| Reconhecimento / Recuperação / Recombinação / Produção | Páginas de prática limpas |
| Gabarito | Final da unidade ou apêndice do consolidado |
| Autoavaliação | Página final |
| Artefato prático | Página final, separado do próximo tópico |

---

## Por que isso importa

- Aumenta a dificuldade real de forma saudável
- Fortalece a sensação de “eu consegui”
- Impede que o material vire apostila de cópia
- Melhora o valor percebido da prática

---

## Critério de conformidade

Uma página de produção está correta somente se:
1. O aluno precisa recuperar, não apenas copiar
2. Não há banco completo visível
3. Não há resposta visível
4. O apoio, se existir, é mínimo e controlado
