# Fontes de Assets Aprovadas

## Objetivo

Evitar que a IA de execução saia caçando assets aleatórios e quebre a identidade do produto.

Use apenas fontes consistentes, limpas e adultas.

---

## 1. Ícones

### Preferenciais
- **Lucide Icons** — primeira escolha
- **Phosphor Icons** — alternativa
- **Tabler Icons**
- **Heroicons**

### Estilo
- linha fina
- minimalista
- monocromático ou com a paleta já usada no template
- sem mascotes
- sem estilo cartoon infantil

### Usos recomendados
- check
- seta
- escrita
- fala / som
- atenção
- mapa
- estrela de conquista

---

## 2. Imagens para matching e cenas

### Fontes preferenciais
- **Pexels**
- **Unsplash**
- **Openverse**

### Estilo desejado
- foto real clean
- ou ilustração minimalista adulta
- boa iluminação
- pouca poluição visual
- fácil de “ler” em tamanho pequeno no PDF

### Temas úteis por unidade
- estudante / sala de aula
- professor
- cumprimento / conversa
- objetos da sala
- café / restaurante
- relógio / agenda
- mapa / localização
- comida / bebida
- preferências / escolha
- rotina diária

### Evitar
- stock artificial demais
- meme
- caricatura infantil
- imagem com texto embutido
- composição confusa

---

## 3. Prática de hanzi

### Fonte principal no repositório
- `references/material/PRATICA-DE-ESCRITA.svg`

### Alternativas técnicas
- grade 田字格
- grade 米字格
- componente SVG simples reutilizável

### Preferência
Sempre que possível, preferir SVG/vetor em vez de raster.

---

## 4. Elementos já existentes do produto

Reutilizar ao máximo:
- ornamentos atuais do template
- barras de seção
- cores já definidas
- tipografia já usada
- estrutura visual da família B

Não misturar outro “skin” visual.

---

## 5. Regras de uso

1. Não baixar pacotes enormes de assets aleatórios
2. Não criar personagem novo para o produto neste ciclo
3. Não trocar a identidade visual base
4. Preferir poucos elementos excelentes a muitos elementos medianos
5. Manter consistência entre B02 e B11

---

## 6. Política prática para a IA executora

Se precisar de imagem:
1. primeiro tentar resolver com tipografia + ícone + layout
2. só então buscar foto/ilustração nas fontes aprovadas
3. manter o recorte simples e legível

Se precisar de ícone:
1. Lucide
2. Phosphor
3. só depois outra biblioteca equivalente
