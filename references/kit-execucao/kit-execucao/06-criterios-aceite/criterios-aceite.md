# Critérios de Aceite — Próxima Versão

A próxima versão só deve ser considerada pronta para avançar se os itens abaixo forem atendidos.

## P0 — Bloqueadores

- [ ] Nenhuma tabela de autoavaliação apresenta colapso de linha
- [ ] Todos os critérios de autoavaliação têm no máximo 1 linha
- [ ] Todos os critérios são observáveis e comportamentais
- [ ] Artefato Prático e Próximo Tópico estão visualmente separados
- [ ] Não há gabarito na mesma página do exercício
- [ ] Não há banco de palavras completo na página de produção
- [ ] Não há mapa completo na página de produção ativa

## P1 — Experiência e valor percebido

- [ ] Instruções principais foram reescritas no tom ativo e adulto
- [ ] Espaços vazios principais têm função nomeada
- [ ] Instrução de oralidade aparece em recuperação e produção
- [ ] Existe pelo menos um componente de prazer visual por unidade
- [ ] Prática de hanzi ou matching visual está presente de forma clara
- [ ] A página de produção continua forte e utilizável
- [ ] A identidade visual base foi preservada

## P2 — Qualidade de publicação

- [ ] Conferência conteúdo↔PDF continua passando
- [ ] Revisão visual humana feita em escala real
- [ ] Não há infantilização do material
- [ ] Não há mudança caótica de estilo entre unidades
- [ ] O consolidado permanece coerente

## Critério qualitativo final

O material deve continuar inteligente e metodologicamente sólido,  
mas também deve parecer mais prazeroso, mais completo e mais fácil de querer usar de novo.
