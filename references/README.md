# Referências

Esta pasta reúne materiais usados para orientar o conteúdo, a linguagem visual e as decisões editoriais do produto.

## Material externo

- `material/hsk1-vocabulario-frases-referencia.pdf`: material enviado pelo usuário, usado como referência lexical para hanzi, pinyin, classe, frases de exemplo e tradução.
- `material/PRATICA-DE-ESCRITA.svg`: referência visual para práticas de escrita.

## Notas e análises

- `repository-notes/`: análises do repositório, decisões de template e registros de revisão.

Materiais em `references/` são fontes de consulta. Eles não são entrada direta do pipeline de produção e não devem ser alterados sem registrar a origem e o uso pretendido.
